# Useful prompts for standard LLMs

Prompts by [Enderman-brewer](https://github.com/Enderman-brewer).

## Current

**AI RP Skill V3.0.0**: [`ai-rp-skill/AI_RP_Skill_V3.0.0.md`](ai-rp-skill/AI_RP_Skill_V3.0.0.md)

A roleplay skill in which the AI is a scene partner. Load it by pasting the file into a chat or uploading it, then asking the model to load it. It starts in Chat Mode and does not begin a scene until asked.

Supported models are listed in the compatibility table inside the skill.
